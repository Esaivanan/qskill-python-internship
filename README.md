# QSkill Python Internship Projects

## Description
This repository contains projects completed as part of the QSkill Python Development Internship. The projects focus on data analysis, machine learning, and numerical computing using Python.

## Completed Tasks

### Task 1: Data Analysis
- Performed data analysis using Pandas
- Calculated averages and insights
- Created visualizations (bar chart, scatter plot, heatmap)

### Task 2: Linear Regression
- Built a machine learning model to predict house prices
- Used Scikit-learn for training and prediction
- Visualized results using Matplotlib

### Task 3: Matrix Operations Tool
- Developed a tool using NumPy
- Supports addition, subtraction, multiplication
- Includes transpose and determinant calculation

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
